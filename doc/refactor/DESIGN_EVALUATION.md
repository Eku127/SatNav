# SatNav 设计评价：卫星地图仿真器

## 设计概述

SatNav 使用 **satsim** 作为卫星地图仿真器，具有以下特点：
- **位置表示**：经度、纬度、高度（用 xyz 坐标系统表示）
- **旋转表示**：roll 角度（航向角）
- **图像生成**：从现有卫星地图上裁剪（crop）出对应区域的图像作为观测

## 设计合理性评价

### ✅ 优点

1. **符合实际应用场景**
   - 卫星地图导航是真实世界的应用场景
   - 与室内导航（Habitat）形成互补，扩展了VLN的应用范围

2. **状态表示简洁**
   - **经纬度+高度**：符合地理坐标系统，直观且标准
   - **roll角度**：对于地面导航，只需要航向角（heading/yaw），roll角度足够表示方向
   - 相比quaternion更简单，计算效率更高

3. **图像生成方式合理**
   - 从现有卫星地图crop图像是高效的实现方式
   - 避免了复杂的3D渲染，降低计算成本
   - 可以充分利用现有的卫星地图数据

4. **与VLN任务匹配**
   - 视觉观测：卫星地图图像（RGB）
   - 语言指令：自然语言导航指令
   - 任务目标：导航到指定位置

### ⚠️ 需要注意的问题

1. **深度信息**
   - 卫星地图不提供深度信息，已移除DepthSensor
   - 仅使用RGB图像作为视觉观测

2. **坐标系统转换**
   - 经纬度到xyz的转换需要考虑地球曲率
   - 距离计算需要使用测地距离（geodesic distance），而不是欧氏距离
   - 需要选择合适的坐标投影系统

3. **roll角度的定义**
   - 需要明确roll角度是相对于哪个方向的（通常是正北方向）
   - 角度范围：0-360度还是-180到180度
   - 与经纬度坐标系统的对应关系

4. **图像裁剪参数**
   - 需要定义裁剪区域的大小（对应地面的实际范围）
   - 需要考虑不同高度（zoom level）下的分辨率
   - 裁剪中心点与经纬度的对应关系

5. **动作执行**
   - MOVE_FORWARD需要考虑地球曲率
   - TURN_LEFT/RIGHT的角度变化需要与roll角度一致
   - 步长（step_size）应该用米或公里表示

## 建议的改进

### 1. 状态表示
```python
class AgentState:
    """智能体状态（卫星地图）"""
    longitude: float      # 经度（度）
    latitude: float       # 纬度（度）
    altitude: float       # 高度（米）
    roll: float          # 航向角（度，0-360，0表示正北）
```

### 2. 坐标转换
- 提供经纬度到xyz的转换函数（考虑地球曲率）
- 提供xyz到经纬度的反向转换
- 使用WGS84坐标系作为标准

### 3. 距离计算
- `geodesic_distance()` 应该使用Haversine公式或Vincenty公式
- 考虑地球曲率，而不是简单的欧氏距离

### 4. 传感器调整
- **RGB传感器**：从卫星地图crop的图像
- **仅使用RGB传感器**：
  - 已移除Depth传感器，简化设计
  - 仅使用RGB图像作为视觉观测

### 5. 图像裁剪参数
```python
class SatelliteImageConfig:
    """卫星图像配置"""
    crop_size_meters: float    # 裁剪区域大小（米）
    resolution: float          # 每像素对应的米数
    zoom_level: int            # 缩放级别
```

## 与室内导航的对比

| 特性 | 室内导航（Habitat） | 卫星地图导航（SatNav） |
|------|-------------------|---------------------|
| **位置** | x, y, z (米) | 经度, 纬度, 高度 |
| **旋转** | Quaternion (4D) | Roll角度 (1D) |
| **坐标系统** | 局部3D坐标 | 地理坐标（WGS84） |
| **距离计算** | 欧氏距离 | 测地距离（Haversine） |
| **图像来源** | 3D渲染 | 卫星地图裁剪 |
| **深度信息** | 有（3D场景） | 无或高度图 |
| **场景范围** | 单个建筑物 | 整个地球表面 |
| **动作步长** | 0.25米 | 几米到几十米 |

## 总结

**总体评价：设计合理且实用**

卫星地图VLN是一个有意义的应用场景，设计简洁且符合实际需求。主要需要注意：
1. 坐标系统的正确转换
2. 距离计算的准确性（使用测地距离）
3. 深度信息的处理（移除或替换）
4. 图像裁剪参数的合理设置

该设计为VLN任务提供了新的应用领域，具有良好的实用价值。
