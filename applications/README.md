# SatNav Applications

Small tools and demos built around SatNav.

## Apps

- [Map Downloader](map_downloader/README.md): download Google or Mapbox satellite GeoTIFF scenes required by SatNav episodes.
- [Episode Processing](episode_processing/README.md): inspect per-city episode sources and build train/validation release splits.
- [SatSim Viewer](satsim_viewer/README.md): interactively inspect satellite maps and SatNav VLN episodes.
- [Trajectory Generation](trajectory_generation/README.md): generate trajectory training data from SatNav episodes.
