# SatNav Dataset Module

This package contains the dataset loaders used by SatNav tasks, offline training,
and evaluation.

## Datasets

### `SatNavDataset`

`SatNavDataset` loads SatNav VLN episodes from plain JSON or gzipped JSON files
and converts them into `VLNEpisode` objects.

Each episode may include:

- `episode_id`
- `scene_id`
- `start_position`
- `start_rotation`
- `goals`
- `reference_path`
- `instruction`
- `trajectory_id`
- `trajectory_type`

It also supports optional filtering by scene or episode id through the dataset
configuration.

### `OfflineTrajectoryDataset`

`OfflineTrajectoryDataset` is the default training dataset for the current
Seq2Seq and CMA baselines. It reads pre-rendered trajectory data generated by
`applications/trajectory_generation/`.

It loads:

- `annotations.json`
- RGB frame folders under `images/`
- tokenized navigation instructions
- previous actions and teacher actions
- optional inflection weights for imitation learning

This dataset is used by `offline_trainer` for offline imitation learning.

### `RecollectionDataset`

`RecollectionDataset` is retained for future online recollection / teacher
forcing work. It collects observations by executing reference-path actions in
the environment at training time. It is not the default path for the current
quickstart Seq2Seq and CMA training pipeline.

## Typical Flow

```text
SatNavDataset
    -> loads VLN episodes

Trajectory Generation
    -> follows reference paths and writes offline trajectory_data

OfflineTrajectoryDataset
    -> loads trajectory_data for Seq2Seq / CMA training
```

For the baseline training workflow, see
[Training Models with SatNav](../../docs/en-US/training/README.md).
